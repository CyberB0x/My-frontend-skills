# My Frontend Skills

Hi there! 👋  
This repository is where I collect all my practice work, scripts, and mini-projects related to frontend development. It includes both foundational exercises and more advanced tasks I've completed while learning modern web technologies.

Working through these topics helped me build solid skills in HTML, CSS, JavaScript, responsive design, DOM manipulation, backend integration, and more. I've also used Git and GitHub throughout the process to keep my projects organized and version-controlled.

## What's Included

I structured the materials step by step — from basic to more complex concepts. Here’s a brief overview of the topics covered:

- Fundamentals of HTML, CSS, and JavaScript  
- Frontend development using IDEs  
- Semantic markup, forms, tables, and multimedia  
- Responsive layouts and media  
- Flexbox and CSS Grid  
- Animations, transforms, and transitions  
- DOM manipulation and event handling  
- Object-Oriented Programming in JavaScript  
- Asynchronous JavaScript, promises, backend communication  
- WebSockets and APIs  
- Git and GitHub workflows  
- SEO basics and microdata  
- Modern frontend development approaches

## Why I Built This

First of all, to reinforce my knowledge through practice — I strongly believe real learning happens by doing.  
Second, this repository serves as a record of my progress and can also demonstrate the skills I've acquired so far.
