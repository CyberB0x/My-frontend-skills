Шестнадцатеричные значения (Hexadecimal Values)

Есть еще один способ, с помощью которого вы можете задать любой цвет — шестнадцатеричная кодировка. Она позволяет задать 16 миллионов оттенков — названия для такого количества цветов придумать невозможно, поэтому используют цифры. Шестнадцатеричные значения задаются с использованием символа #, за которым следуют шесть цифр или букв, представляющих интенсивность красного, зеленого и синего цветов (RRGGBB).
